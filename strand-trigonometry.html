E6 Decision Tree: Choosing the Right Trig Rule + Exact Values

CIE gives Sine Rule, Cosine Rule, and $\frac{1}{2}ab\sin C$ on Page 2—but exact values for $0^\circ, 30^\circ, 45^\circ, 60^\circ, 90^\circ$ and trig graph symmetries ($0^\circ \le x \le 360^\circ$) must be memorised.

Ratio $0^\circ$ $30^\circ$ $45^\circ$ $60^\circ$ $90^\circ$
$\sin\theta$ $0$ $\frac{1}{2}$ $\frac{\sqrt{2}}{2}$ $\frac{\sqrt{3}}{2}$ $1$
$\cos\theta$ $1$ $\frac{\sqrt{3}}{2}$ $\frac{\sqrt{2}}{2}$ $\frac{1}{2}$ $0$
$\tan\theta$ $0$ $\frac{\sqrt{3}}{3}$ $1$ $\sqrt{3}$ undef.

1. Right-Angled vs Non-Right-Angled

  • Has a $90^\circ$ angle? Use Pythagoras or SOHCAHTOA.
  • No $90^\circ$ angle & know a matching pair (angle + opposite side)? Use Sine Rule.
  • No matching pair (SAS or SSS)? Use Cosine Rule.

2. Trig Equations in $0^\circ \le x \le 360^\circ$ (E6.4)

  • $\sin x = k$: Second solution via $180^\circ - x_1$ (if $< 0$, use $180^\circ + \alpha$ and $360^\circ - \alpha$).
  • $\cos x = k$: Second solution via $360^\circ - x_1$ (symmetric about $180^\circ$).
  • $\tan x = k$: Repeats every $180^\circ$, so $x_2 = x_1 + 180^\circ$.

3. Shortest Distance from a Point to a Line

  • The shortest distance from vertex $C$ to line $AB$ is ALWAYS the perpendicular height $h$.
  • Find $\text{Area} = \frac{1}{2}ab\sin C$, then equate to $\frac{1}{2} \times AB \times h$ (or use $h = b\sin A$).

4. 3D Trigonometry Strategy

  • Step 1: Find the diagonal across the 2D base first using Pythagoras (or Cosine Rule).
  • Step 2: Extract the vertical right-angled triangle containing the 3D line and its base projection, then use $\tan^{-1}\left(\frac{\text{height}}{\text{base diagonal}}\right)$.

High-Frequency CIE Examiner Traps

  • Calculator in Radians mode: Always check the top of your calculator screen shows D / DEG before Paper 4.
  • Ambiguous case of the Sine Rule: Your calculator’s $\sin^{-1}(k)$ always returns an acute angle $\theta$. If the diagram or text states the angle is obtuse, you must take $180^\circ - \theta$.
  • Rounding angles vs lengths: CIE standard accuracy is 1 decimal place for angles in degrees (e.g. $42.7^\circ$) and 3 significant figures for lengths/areas, unless stated otherwise.
